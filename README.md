# Studio Toolkit

A free, open-source Roblox Studio plugin with small tools that save you clicks when building.
Select some parts or models, click a tool, done. Every tool can be undone with **Ctrl+Z**.

## Tools

| Tool | What it does |
|---|---|
| **Anchor All** | Anchors every part in the selection, including parts inside models. |
| **Copy Look** | Copies color, material and transparency from the first selected part to the others. |
| **Randomize Rotation** | Spins each selected part or model to a random angle. Great for trees and rocks. |

More tools are on the way, and you can add one yourself. See [Contributing](#contributing).

## Install

1. Download `StudioToolkit.rbxm` from the [latest release](../../releases/latest).
2. In Roblox Studio, open the **Plugins** tab and click **Plugins Folder**.
3. Move the downloaded file into that folder.
4. Restart Studio. A **Toolkit** button appears in the Plugins tab.

## Use

1. Click **Toolkit** to open the panel.
2. Select parts or models in your place.
3. Click a tool. The bar at the bottom tells you what happened.
